# AeroRoute

AeroRoute — децентрализованная платформа «Uber для доставки на дронах», где заказчики и независимые операторы дронов взаимодействуют напрямую без компании-посредника.

## Как это работает

1. **Создание заказа (Next.js):** пользователь открывает веб-приложение, указывает точки маршрута и параметры доставки (лекарства, документы, небольшие посылки).
2. **Гарантия оплаты (Solana smart contract):** при создании заказа оплата блокируется в escrow-смарт-контракте, чтобы средства не списывались раньше подтверждённой доставки.
3. **Подхват заказа оператором:** свободный дрон независимого владельца принимает заявку.
4. **Реалтайм-трекинг (Cloud Firestore):** местоположение дрона и статус заказа обновляются на экране мгновенно в режиме реального времени.
5. **Автовыплата после доставки:** после подтверждения доставки смарт-контракт автоматически переводит средства пилоту/владельцу дрона.

## Ключевая ценность

- **Без посредника:** нет централизованной компании, удерживающей контроль над сетью.
- **Честные расчёты:** escrow-механика на блокчейне защищает и заказчика, и исполнителя.
- **Открытая DePIN-сеть:** любой владелец дрона может подключиться и зарабатывать на доставке в глобальной сети.
